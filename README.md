# TP 3 — Boucles & Tableaux en Java

Ce projet regroupe une série d'exercices réalisés en **Java** dans le cadre du module **Fondamentaux et Concepts Avancés de la Programmation Java**.

L'objectif de ce TP est de renforcer la maîtrise des **boucles, tableaux, matrices et algorithmes de base** à travers différents problèmes pratiques.

## 📚 Exercices

### Exercice 5 — Rotation d'une matrice N×N

Rotation d'une matrice carrée de **90° dans le sens horaire**, directement dans la matrice, sans utiliser un deuxième tableau.

La solution utilise :

* la transposition de la matrice ;
* l'inversion de chaque ligne ;
* des échanges de valeurs avec une variable temporaire.
<img width="1366" height="768" alt="ex5" src="https://github.com/user-attachments/assets/19fa60e9-6cca-4a74-842f-f6b9706c119b" />

### Exercice 6 — Fenêtre glissante

Calcul du nombre de valeurs distinctes dans chaque fenêtre de taille `k` d'un tableau.

L'algorithme utilise :

* un tableau de fréquences ;
* la technique de **fenêtre glissante** ;
* des boucles ;
* une complexité en `O(n + MAXV)`.

## 🎯 Objectifs pédagogiques

Ce TP permet de développer les compétences suivantes :

* maîtriser les boucles en Java ;
* manipuler des tableaux et des matrices ;
* écrire des méthodes réutilisables ;
* résoudre des problèmes algorithmiques ;
* comprendre et améliorer la complexité des algorithmes ;
* travailler avec des calculs numériques ;
* effectuer des opérations directement sur les tableaux.
